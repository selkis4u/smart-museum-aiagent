# 검색 평가 질의 (NFR-17)

`retrieval_queries.jsonl` 한 줄이 질의 하나다. 유물 4점(A001~A004)마다 5건, 모두 20건.

| 필드 | 뜻 |
|---|---|
| `artifact_id` | 관람 판정 이벤트의 유물 ID. 검색은 이 ID로 청크를 먼저 거른 뒤 수행 |
| `expected` | 정답 청크 ID. 이 중 하나라도 Re-ranking 상위 3개에 들어오면 통과 |
| `distractors` | 섞이면 안 되는 다른 유물의 청크(혼동 테스트). 필터를 끈 검색에서도 상위 3개에 들어오지 않아야 함 |
| `type` | `fact` 사실 / `conflict` 자료끼리 값이 다름(해설은 e뮤지엄 값) / `confusion` 비슷한 유물과 혼동 / `behind` 비하인드(note) 검색 |

통과 기준(NFR-17): 상위 3개 정답 포함 90% 이상(20건 중 18건), 다른 유물 고유 청크 혼입 0건.

- `conflict` 문항은 검색만으로는 판정하지 않는다. 해설 생성 결과가 e뮤지엄 값을 쓰는지 NFR-07 검수에서 함께 본다.
- 청크를 다시 만들면 chunk_id가 바뀔 수 있으니 `expected`를 다시 확인한다.
