# 도슨트 스크립트는 관람 판정 시점에 실시간으로 생성한다

도슨트 스크립트를 유물 등록 시 미리 만들어 검수하는 대신, 관람 판정 시점에 공식 도록 RAG와 Web Search를 결합해 매번 실시간으로 생성한다. 1차 개발의 목적이 "보고 → 생각하고 → 판단하는" Agent 기술 구현을 보여 주는 데 있기 때문이며, 응답 지연과 사전 검수 불가는 감수한다.

## Considered Options

- **사전 생성 + 관리자 검수 + 최신 소식 주기 갱신**: 해설이 즉시 시작되고 사실 오류를 검수로 막을 수 있지만, 관람 시점의 Agent 판단이 드러나지 않는다.
- **사전 생성 + 관람 시 최신 소식 한 줄만 실시간 추가**: 절충안이지만 구현 경로가 두 개로 늘어난다.

## Consequences

- 해설 시작까지 지연이 생긴다. LLM 스트리밍과 문장 단위 TTS로 첫 문장부터 읽고, Dwell Time 동안 RAG·Web Search를 미리 시작해 체감 지연을 줄인다.
- 생성이 실패하거나 늦으면 대체 해설로 넘어간다: 유물마다 공식 도록만으로 미리 만든 기본 원고의 문장별 음성 파일을 즉시 재생한다. (2026-11-02 변경: 재생성·마지막 성공 원고 방식은 LLM·TTS가 인터넷에 의존해 네트워크 단절 시 동작하지 않으므로 폐기)
- 사전 검수가 불가능하므로 해설 사실성(NFR-07)은 생성 원고와 출처를 세션 기록으로 남겨 사후 검수한다.
- 같은 유물이라도 관람마다 해설이 달라진다. 테스트는 원고 내용이 아니라 도록 근거 포함 여부와 출처 기록으로 검증한다.
- 운영 단계에서 지연·비용·사실성 문제가 커지면 사전 생성 방식으로 바꾸고 이 ADR을 대체한다.
